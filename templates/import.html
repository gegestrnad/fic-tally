Batch import

Paste CSV or JSON, or upload a .csv / .json file. Everything is written in one transaction; duplicates follow the policy below. Max 1000 rows per request.

If a file is chosen it takes precedence over the pasted text.

Cancel

CSV columns

First line must be a header containing at least title. Other columns (all optional):

title, alt_titles, type, author, year,
pub_status, description, tags,
source_url, cover_url, parent_id,
total_chapters, total_is_known, status,
chapter_num, chapter_label, rating,
notes, bookmark_url, bookmark_label

Notes

  • Tags separate on commas, semicolons, or pipes.
  • Alternative titles separate on newlines, semicolons, or pipes (not commas).
  • pub_status values: ongoing, completed, hiatus, cancelled — the IDs shown in mono on the options page (custom options you added there are valid too).
  • total_is_known accepts true/1/yes/on.
  • JSON uses the same field names as the JSON export — export backs up, import restores.
  • Fuzzy near-matches (translated titles) are flagged in the results but still imported.
  • Scripting? POST /api/series/batch takes the same JSON over HTTP — one request, one transaction.
